# Draft expert pilot-rating plan(DRAFT -- Must be jointly frozen with the user and experts before implementation)

Status:Draft. Based on audit handoff §8.6-8.7, §9.3(R3). This document does not mean that experts have confirmed participation,
nor that the plan has been frozen;the purpose of pilot rating is itself to test whether these materials are sufficient and how long it takes to rate one case.

## 1. Pilot-rating cases(5 cases suggested,covering three types of situations)

| Case | Type | Rationale for selection |
|---|---|---|
| Sub09_P | All 7 channels present,moderate severity(0.62 m/s) | Typical representative case;includes the interpretive challenge of full-cycle RF/BF/ERS activation |
| Sub05_P | All 7 channels present,severe(0.14 m/s) | Low speed+large deviations:test whether the boundary of "no attribution under speed confounding" is respected;handling of GAS 13.3 max\|z\| |
| Sub50_P | All 7 channels present,mild(0.83 m/s) | Many boundary-crossing activation intervals;handling indeterminacy with low pelvic ROM and high GVS |
| Sub47_P | All EMG missing(documented lack of analog acquisition) | Missing-information case:whether the report honestly limits its scope |
| Sub49(healthy,leave-one-out reference) | Healthy control | Interpretation task with a known label:whether values within the healthy range are pathologized |

Note:All five cases have been repeatedly used for development,and pilot-rating results are only for refining materials and procedures,
and must not be used as confirmatory evidence of model capability.

## 2. Materials seen by raters(one "data card" per case)

1. Blinded report(from the formal batch packets/,anonymous ID).
2. The complete v2 input text for the case(including the metric-definition block and the "actual reference composition" line)—raters must base
   their judgment on the same information as the model,not on writing style.
3. Key curve plots:7 EMG envelopes(with detected intervals and threshold lines marked)+ 4 sagittal-plane angle curves
   (Overlaid with healthy reference mean±1SD; EMG also shows threshold lines and detected intervals). Current entry point:
   [Brief clinical data cards](data_cards_v5/index.html), generated by `scripts/build_expert_trial_package.py`.
   Currently preparation materials for the expert checklists; blinded model reports are not yet included.
4. Metric reference card:healthy p95 for each muscle's max|z| (3.65-4.61), healthy CCI percentiles,
   GPS-like percentiles, supported speed range (0.80-1.79 m/s)——consistent with the input definitions block.
5. Expert checklist for this case (drafted by the first expert and reviewed by the second during trial rating):
   - Findings that must be mentioned (omissions incur completeness deductions)
   - Allowed interpretations (within the evidence provided)
   - Inferences with insufficient evidence (asserting them in the report counts as overinterpretation; marking them as indeterminate in the report counts as correct)

## 3. Rating structure (three levels, from §8.6)

- **Level 1 Numerical facts** (machine-verifiable + expert spot checks):whether values, laterality, intervals, and rankings are consistent with the input
  . Binary safety items are listed separately:laterality consistency, normal/abnormal direction (according to metric-specific references;
  when no reference is available, writing "indeterminate" in the report is the correct behavior).
- **Level 2 Interpretive boundaries** (expert Likert 1-5 + item-by-item annotation):whether interpretations are supported,
  whether there is overinterpretation, whether uncertainty is expressed appropriately, coverage of important findings, and clinical usability.
- **Level 3 Clinical mechanisms**:outside the scope of this study, not rated. An expert judgment of "insufficient data to support spasticity"
  ≠ proof of no spasticity; this boundary is included in the rating instructions.

## 4. Procedure

1. ≥2 raters with gait/surface EMG experience (relevant experience matters more than professional title), initially rating independently,
   blinded to model identity; retain the original disagreements.
2. After trial rating, record:time spent per case, gaps in materials, and rule ambiguities; revise and freeze the formal protocol accordingly.
3. In the formal round, discuss disagreements or use third-person adjudication according to the prespecified procedure.
4. Statistical analysis uses the participant as the repeated-measures unit; raters are crossed, not independent samples.

## 5. Rating form template and completion conventions

See `rating_form_template.csv` in the same directory (each row = one rater x one anonymous report).

- **batch_id**:enter the package batch directory name (e.g., `batch-20260916T...`), ensuring that each rating can be traced to
  the exact report set and answer key.
- **Strictly distinguish two types of NA** (see `eval/rubric.py` for the full anchors):
  - *The model correctly expresses indeterminacy* → score each dimension normally (usually favorably), and in
    `model_indeterminate_handling` enter correct;
  - *The expert cannot assess* → enter `NA-cannot-rate` for the dimension and specify the reason in `cannot_rate_reasons`
    ——this is feedback on the rating materials/rules; every instance must be collected during trial rating (`material_gaps_noticed`).
- **Reference alignment**:the reference card within each case's data card specifies whether pooled or leave-one-out reference applies to that case and the corresponding calibration column;
  all ratings must follow that card; references must not be applied across cases.
- **1-5 anchors**:all four Likert dimensions have 1/2/3/4/5 behavioral anchors (rubric.py),
  completeness is rated against the adjudicated checklist for this case, not personal expectations.
