# 专家试评方案草案(DRAFT -- 需与用户及专家共同冻结后方可执行)

状态:草案。依据 audit handoff §8.6-8.7、§9.3(R3)。本文件不代表专家已确认参与,
也不代表方案已冻结;试评的目的本身就是检验这套材料是否充分、评一例需时多久。

## 1. 试评病例(建议 5 例,覆盖三类情形)

| 病例 | 类型 | 选择理由 |
|---|---|---|
| Sub09_P | 完整 7 通道,中等严重度(0.62 m/s) | 典型主流病例;含 RF/BF/ERS 全周期激活的解读难点 |
| Sub05_P | 完整 7 通道,重度(0.14 m/s) | 低速+大偏差:检验"速度混杂不可归因"边界是否被尊重;GAS 13.3 max\|z\| 的处理 |
| Sub50_P | 完整 7 通道,轻度(0.83 m/s) | 跨界激活区间多;骨盆低 ROM 高 GVS 的不可判定处理 |
| Sub47_P | EMG 全缺失(文档记载无模拟采集) | 缺失信息病例:报告是否诚实限定范围 |
| Sub49(健康,留一参考) | 健康对照 | 已知标签下的解释任务:健康范围内数值是否被病理化 |

注:五例均为已反复用于开发的病例,试评结果只用于打磨材料与流程,
不得作为模型能力的确认性证据。

## 2. 评分者看到的材料(每例一份"数据卡")

1. 盲化报告(来自正式批次 packets/,匿名 ID)。
2. 该例的 v2 完整输入文本(含指标定义块与"实际参考构成"行)——评分者必须基于
   与模型相同的信息评判,不能凭文风。
3. 关键曲线图:7 条 EMG 包络(标出检测区间与阈值线)+ 4 条矢状面角度曲线
   (叠加健康参考带)。[待生成:build_trial_data_cards 脚本]
4. 指标参考卡:各肌肉 max|z| 健康 p95(3.65-4.61)、CCI 健康分位数、
   GPS-like 分位数、速度支持范围(0.80-1.79 m/s)——与输入定义块一致。
5. 本例专家清单(试评期间由第一位专家起草、第二位复核):
   - 必须提到的发现(漏了算 completeness 扣分)
   - 允许的解释(在所给证据范围内)
   - 证据不足的推断(报告若断言则算过度推断;报告若标注不可判定则算正确)

## 3. 评分结构(三层,来自 §8.6)

- **第 1 层 数字事实**(机器可核 + 专家抽查):数值、侧别、区间、排序是否与输入
  一致。二元安全项单列:侧别一致性、正常/异常方向(按指标特定参考;
  无参考时报告写"不可判定"才是正确行为)。
- **第 2 层 解释边界**(专家 Likert 1-5 + 逐条标注):解释是否有依据、
  是否过度推断、不确定性表达是否恰当、重要发现覆盖、临床可用性。
- **第 3 层 临床机制**:超出本研究范围,不评。专家判"数据不足以支持痉挛"
  ≠ 证明无痉挛,此边界写入评分说明。

## 4. 流程

1. ≥2 位有步态/表面肌电经验的评分者(相关经验重于职称),先各自独立、
   模型盲评;保留原始分歧。
2. 试评后记录:每例耗时、材料缺口、规则歧义;据此修订并冻结正式方案。
3. 正式轮再按预定程序讨论分歧或第三人裁决。
4. 统计以受试者为重复测量单位;评分者交叉、非独立样本。
