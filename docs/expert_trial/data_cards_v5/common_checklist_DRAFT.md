# Common review checklist (shared by all five cases, review only once)

- [ ] G01 [allowed_interpretation] The report should capture meaningful findings and need not repeat every number. When evidence is insufficient, it may state “currently indeterminate”; please use “Modify” to enter the wording you would like the report to use.
- [ ] G02 [cannot_infer] These materials alone cannot establish a diagnosis of spasticity, muscle weakness, or contracture, nor can they be used to prescribe a treatment plan. Information not recorded should not be guessed or treated as normal.
- [ ] G03 [cannot_infer] The reference bands in the figures and the calculated metrics only aid comparison; they are not diagnostic cutoffs for disease. Walking speed also affects comparison; EMG curve amplitude cannot be directly equated with muscle strength.
- [ ] G04 [allowed_interpretation] There is no need to repeatedly check every activity interval: a curve starting at 0% does not mean the muscle only begins activation at that point, and remaining above threshold throughout does not mean sustained abnormal contraction. Flag issues only when the report misinterprets these meanings. Figures and detailed references not received by the model cannot be grounds for omission deductions.
