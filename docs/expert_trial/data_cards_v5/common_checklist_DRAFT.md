# 通用审核清单（五例共用，仅审核一次）

- [ ] G01 [allowed_interpretation] 报告应抓住有意义的发现，不必复述每个数字。证据不足时可以写“目前无法判断”；请用“修改”写出您希望报告采用的说法。
- [ ] G02 [cannot_infer] 这些资料不能单独确诊痉挛、肌无力或挛缩，也不能据此开出治疗方案。没有记录到的信息，不应猜测或当作正常。
- [ ] G03 [cannot_infer] 图中的参考带和计算指标只帮助比较，不是疾病诊断界限。走得快慢也会影响比较；肌电曲线的高低不能直接当作肌力大小。
- [ ] G04 [allowed_interpretation] 不必反复核对每个活动区间：曲线从0%开始不代表肌肉此时才启动，全程超过阈值也不代表持续异常收缩。只在报告误解这些含义时指出问题。模型没收到的图形和详细参考，不能作为漏报扣分依据。
