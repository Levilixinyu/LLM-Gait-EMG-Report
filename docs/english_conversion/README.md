# English working edition

The project working materials, original expert submissions, adjudication records,
data cards, review interface, filenames, and issued rating packages have been
converted to English. Existing English model responses and scientific input text
were preserved. This is a language conversion, not a new trial or expert review.

The original evidence is preserved outside the project under
`/Users/lixinyu/ProjectArchives/LLM-Gait-EMG-Report/`. Archived payloads are read-only.
Both the active project and archive have explicit access rules; default search
excludes the archive, and the project contains no links into it. Routine generation,
scoring, analysis, and verification must not read the archive or use it as a fallback.
Access it only for explicitly authorized provenance verification or restoration.

## Evidence and hashes

[manifest.json](manifest.json) maps every changed original to its English working
copy, recording separate SHA-256 hashes. Original archive paths are percent-encoded
identifiers for provenance, not input paths for routine workflows. The external
archives retain their own original-file manifests.

Historical source hashes, dates, opinions, pending states, and signature provenance
have not been rewritten to imply new evidence. References in historical documents
to "original" or "unchanged" describe the source at that time. A translated expert
statement is not a fresh confirmation of its English wording.

Q055 remains an AI-origin adjudication subsequently registered as human-reviewed
on the user's confirmation. It is not relabeled as an independent initial judgment
by a third human expert. Original disagreements and the absence of supplied human
reviewer names or dates remain visible.

The original freeze manifests intentionally retain historical source hashes.
They do not certify translated bytes. Do not regenerate the completed trial or
replace its historical hashes to make a legacy freeze check pass. Verify this
English snapshot separately:

```sh
python scripts/verify_english_working_copy.py
```

Later intentional edits may cause a conversion-snapshot mismatch; investigate and
record the new version rather than restoring originals automatically.

## Scope and verification

Translation used API output followed by assistant contextual translation and
correction. Review emphasized scientific numbers, report/case IDs, existing English
quotations, negation and conditional rules, coverage versus error, and pending versus
confirmed decisions. Repeated text was reused consistently. This is not a certified
human translation review.

Validation covers workbook values and formulas, dropdowns, English sheet names,
file references, original issued ZIP membership, unchanged anonymous report text,
source archive integrity, and program and browser checks. See
[validation.json](validation.json) for the recorded results.

The original dataset and existing English scientific plots remain unchanged. Two
retired Chinese UI screenshots are represented in the working tree by clearly
labeled English text transcriptions; exact images remain archived. The current v5
UI screenshot and browser-check record were generated by a fresh English smoke
test. The screenshot uses synthetic test entries, not new expert opinions.

English UI drafts use a separate browser-storage namespace, preventing old-language
drafts from being silently loaded. Existing case IDs and historical review-version
identifiers remain traceable to their original evidence.
