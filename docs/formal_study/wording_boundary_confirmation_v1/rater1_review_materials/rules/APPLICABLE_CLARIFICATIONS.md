# Applicable discussion and annotation rules

D03 (study-lead clarification after initial independent scoring):

Interpret clinical follow-up questions as possibilities to be verified, not established mechanisms or diagnoses. Mentioning spasticity, compensation, instability, or a phase-related clinical task in a question is not itself an error. Separately inspect independently checkable false facts and explicit assertions that an abnormal finding has already been observed. This boundary preserves the existing factual-error rule; it is not an additional user signature.

Pathology annotation (study-lead confirmation, 2026-09-23):

For an unsupported pathological/clinical-impairment inference, use the human reviewer's explicit semantic judgment and pathology annotation. A simultaneous E02 category tag is not required.

- No flag is inferred solely from a question, E07, a numerical deviation, or healthy-group membership.
- A confirmed in-scope issue and explicit expert annotation are required for a positive confirmed pathology outcome.
- Pending and missing annotations remain subject to the approved uncertainty rules.
- Preserve all personal category choices and original independent scores.
