# Prospective review instructions for the repeated-generation supplement

Prepared before any new response. Scope: 225 new stroke reports, three human reviewers, every report independently assessed by each reviewer. The study lead confirmed reviewer capacity and instructed generation. This document consolidates existing rules; it is not an expert signature or a record of fresh clinical validation.

Use the existing approved rubric v2 and its approval record, the final case-specific requirements for the selected 25 stroke cases, and the exact saved inputs and supporting reference materials. Historical developmental examples are teaching examples, not the requirement list for this new batch. The old rubric's historical draft labels are superseded by its existing approval record. A new response does not inherit any old response's label.

## Coverage

- Covered requires all substantive components of one allowed route. Partially covered requires a meaningful subset. Not covered means no substantive component; missing review material is separate.
- Apply the existing D01 clarification from the first pass: correct substantive values without the required interpretation of principal differences are Partially covered.
- Apply D02: a magnitude-sorted list alone does not explain a required principal difference. Accept equivalent explanations anywhere in the report; do not impose keywords or an extra principal joint that the requirement does not specify.
- Keep case denominators fixed. Reference-comparability coverage (G03) is separate and applies once to each report. Meaningful reference limitations and their implication for attribution/diagnosis matter; a rote age/speed keyword list is not required.
- Curves and reference cards support checking, but do not create mandatory findings from information unavailable to the model. Faithfully captured short, refused, malformed or truncated output is still assessable for the content actually present.

## Errors and uncertainty

- Apply the existing E01-E09 categories to report-scoped claims, with exact quotations and reasons. More than one tag does not create more than one issue group. Repeated equivalent claims within one report share a group; distinct claims remain separate.
- Apply D03: a clinical follow-up question can propose a possibility for verification. A question mentioning a mechanism, compensation or impairment is not by itself an assertion that it is observed. Separately inspect false numbers, wrong metric identities and explicit unsupported factual premises.
- Retain Error, Acceptable, Pending adjudication and Outside case-error scope as distinct judgments. Ambiguity does not require unanimity or automatic clearance. Do not copy a historical individual preference as a newly agreed rule.
- Record clinical magnitude, statistical significance, phase attribution, threshold interpretation and reference classification according to their existing context-sensitive rules. Do not treat one keyword as an automatic error or exemption.
- A delivery failure with no text is an operational no-report state, not an expert-rated error-free report. Any-error is positive when the reviewer identifies an Error, negative only after a complete review without Error/Pending, and otherwise unknown.

## Independence and packet handling

Use your own randomized packet. Do not consult peer ratings or original case-level ratings while making the new judgments. Provider/repetition identifiers will be concealed, but report wording remains verbatim. Disclose any prior access to model identities or model-comparison results before scoring; do not claim perfect blinding merely because the new packet has opaque IDs. Familiarity with the original cases and scoring discussions is expected and will be reported.

Return your own unmodified first-pass judgments before any discussion. The supplement's principal rating analyses retain all three reviewers separately. Discussion, if later undertaken, forms a separate secondary record and is not a reason to erase original disagreement. There is no prescribed model ranking or required direction of score changes.

The scoring package will contain the reports, full inputs, curves/reference materials, 119 applicable stroke requirements, the approved rubric and examples, these instructions, a blank response workbook and an exposure/completion declaration. This planning folder contains model identities and is not the blinded packet.
